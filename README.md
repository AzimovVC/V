# Дом внутри — прототип

2D-игра о внутреннем мире. Ты — «Я», проснувшееся в подвале дома-человека. Комнаты — переживания, ярусы — от выживания до смысла. Заглушить симптом можно быстро, но он вернётся с долгом. Выкорчевать корень дорого, зато навсегда. Игра не лечит и не осуждает, она даёт карту.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173, пересборка на лету
npm run build    # typecheck + минифицированная сборка в dist/ (статика, можно выложить куда угодно)
```

Нужны только `typescript` и `esbuild` (dev-зависимости). В рантайме зависимостей нет, бандл ≈ 73 КБ.

**Управление.** Экранные ◀ ▶ и одна контекстная кнопка справа (её подпись меняется: «Отдохнуть», «Спрятаться», «Труба», «Подышать»…). Работает мультитач. Клавиатура: ← → / A D, Пробел / E — действие, F — мебель, M — звук, Esc — закрыть окно. Лучше играть в наушниках.

## Что есть в прототипе

Один ярус подвала, три комнаты, буря, один жилец.

| | |
|---|---|
| **Моя комната** | лампа (отдых), шкаф (прятаться), окно (погода, чинится), тетрадь (воспоминание — ключ), обустройство в 3 слота |
| **Котельная** | течёт труба: **тряпка** (дёшево, 75 с, долг +1, вернётся сильнее) или **найти причину** (дорого, ≈9 с на месте, навсегда, даёт «Границу» и печку). Корень доступен только после воспоминания в тетради. Есть ниша для укрытия и ржавый засов на полу |
| **Кладовая** | заперта, пока труба не вылечена. В окне всегда тишина. Коробка с ковром — финальное тихое событие, после него в двери появляется «Подняться» |
| **Критик** | шаги → стук (3 раза) → входит и обходит комнаты. Сначала прячешься (шкаф/ниша); после корня Котельной можно «сказать „хватит“» через дверь. Заметил — откат к лампе с потерями, но без game over |

Малое действие есть всегда: «Подышать» (удержание) возвращает немного огонька даже в самый плохой момент. Пропущенные дни не наказываются: при загрузке огонёк подтягивается к 50.

## Архитектура

```
index.html, style.css          DOM-оболочка: HUD, кнопки, окна поверх canvas
scripts/build.mjs              esbuild: dev-сервер и prod-сборка
src/
  main.ts                      точка входа: титул → игра, главный цикл
  config/balance.ts            ★ ВСЕ ЧИСЛА (энергия, таймеры, цены, погода, жилец, предметы)
  data/*.json                  содержание: комнаты и фикстуры, предметы, жильцы, погода, тексты
  data/index.ts                типизированная загрузка + геометрия мира
  core/
    game.ts                    Game: состояние + рантайм + цикл update(dt)
    state.ts                   GameState, сохранение (localStorage), производные величины
    events.ts                  типизированная шина событий
    input.ts                   сенсорные кнопки (pointer events) + клавиатура
    types.ts
  systems/                     чистая логика, каждый файл — одна забота
    player.ts                  движение, границы, смена комнат
    energy.ts                  «Огонёк»: тает вне света, растёт у лампы
    world.ts                   течь/тряпка, работа над корнем, погода дня, гром
    tenant.ts                  автомат жильца: away → steps → knock → enter → patrol → leave
    interactions.ts            контекстное действие для единственной кнопки
    furnish.ts                 слоты, поставить/убрать/починить
    penalty.ts                 откат без game over (окно, поломка, «тряска» погоды)
  render/
    sketch.ts                  эскизные дрожащие линии, штриховка
    world.ts                   дом в разрезе, комнаты, актёры
    renderer.ts                камера, слой темноты со светом, свечение, зерно
  audio/audio.ts               процедурный Web Audio (без файлов)
  ui/ui.ts                     HUD, тосты, окна выбора/памяти/мебели
```

**Принципы.**
- *Числа — в `balance.ts`, содержание — в JSON.* Хочешь сделать игру мягче или злее — правишь один файл.
- *Системы не знают друг о друге*, только о `GameState` и шине событий. Звук, UI и тосты подписаны на события (`tenant:knock`, `room:rooted`, `choice:muffle`…), логика о них не знает.
- *Сохраняется только `GameState`* (сериализуемый). Рантайм (таймеры жильца, отдых, камера) при загрузке начинается заново.
- *Сцен как отдельных классов нет:* титул — DOM-оверлей над тем же миром, игра — `Game`. Для одного яруса менеджер сцен был бы лишним; он понадобится вместе с несколькими ярусами.

### Что за что отвечает в данных

- `rooms.json` — палитры «до/после», фикстуры (`type` определяет и рисование, и действие), `lockedBy`.
- `items.json` — названия и описания; **числовые эффекты предметов лежат в `balance.items`**.
- `tenants.json` — маршрут по комнатам, точки остановок, реплики.
- `texts.json` — все тексты игры (тон: мягко, без диагнозов, без «ты должен»).

## Как подкрутить баланс

Всё в `src/config/balance.ts`, у каждой строки есть комментарий. Самое полезное:

| Хочется | Крутить |
|---|---|
| огонёк тает быстрее/медленнее | `energy.darkDrain`, `weather.levels[].drainMult` |
| отдых у лампы быстрее | `energy.lampRestRate` |
| первый визит позже/раньше | `tenant.firstVisitDelay` |
| визиты реже | `tenant.minInterval/maxInterval`, `weather.levels[].tenantIntervalMult` |
| больше времени спрятаться | `tenant.stepsTime`, `knockCount`, `knockInterval`, `noticeTime` |
| корень дешевле/быстрее | `boiler.rootCost`, `boiler.rootWorkTime` |
| долг больнее | `boiler.muffleCostPerDebt`, `weather.debtSeverity`, `tenant.debtIntervalRate` |
| тряпка держит дольше | `boiler.muffleDuration` |
| откат мягче | `penalty.energyLossFrac`, `penalty.energyFloor` |
| больше/меньше слотов | `furnish.slots` |

Для отладки в консоли браузера доступен `window.game` (например `game.state.energy = 100`, `game.rt.tenant.timer = 0` — вызвать Критика сейчас).

## Как проверено

Типы (`tsc --strict`) и сборка чистые. В headless-Chromium (десктоп 1000×560 и телефон 390×844 с тачем) пройдены скриптом: воспоминание → заглушка → возврат течи → корень → способность → открытие Кладовой → коробка → шаги/стук → «Граница» → укрытие в шкафу во время обхода → «заметил» → откат с потерями → засов → потухший огонёк → сохранение/продолжение → лестница. Ошибок в консоли нет.

**Не проверено:** звук. Я не могу его услышать, поэтому код микшера и синтеза проверен только на отсутствие ошибок. Громкости и тембры нужно подстроить на слух (все в `audio/audio.ts`). Баланс времени тоже настроен «на глаз» без живого плейтеста — первые цифры лучше сверить с реальным прохождением.

## Допущения, которые я сделал

- Обустройство: слоты только у «Моей комнаты» (`furnish.slots`), лампа занимает один навсегда — иначе нет смысла в выборе.
- «Ключ в воспоминании»: корень трубы закрыт, пока не прочитана тетрадь.
- Предметы с источниками: засов лежит в Котельной, ковёр в Кладовой, печка — награда за корень. Кресло есть с начала.
- Критик не заходит в Кладовую: это «тихое место», дом его туда не пускает.
- Выбитое окно / сломанный предмет чинятся за огонёк, ничего не теряется насовсем.
- Лестница на выходе (после коробки) пока показывает карточку «прототип заканчивается»; комната «Я» на ярус выше — в следующих шагах.

## Следующие шаги

1. **Живой плейтест и баланс.** Послушать звук, подвинуть тайминги Критика и цены.
2. **Подъём комнаты «Я» на ярус выше** (механика 9): вынести состояние яруса в данные, второй ярус с новыми комнатами.
3. **Остальные жильцы:** Шумный (шум от долга, нужно «ковёр/тишина»), Разрушитель (ломает предметы, нужна граница), Тень прошлого (ходит по маршруту, реагирует на свет). Автомат в `tenant.ts` стоит сделать универсальным по данным `tenants.json`.
4. **Остальные стихии и дни:** морось/штиль как «состояние дня» со сменой, а не только производная от прогресса.
5. **Менеджер сцен** и меню паузы/настроек (громкость, размер текста, режим без таймеров).
6. **Больше способностей из корней** (голос, свет) как разные отпоры, привязанные к комнатам.
7. **Доступность:** субтитры звуков, режим без жителей, контраст.
8. **Арт:** анимации, спрайты вместо процедурных силуэтов, фон ярусов.
9. **Данные:** проверка JSON схемами, редактор комнат.
